# Contributing

Thank you for contributing to GenericSequenceGenerator.

## Development workflow

1. Create a feature branch from `master`.
2. Keep changes focused and follow the existing C# style.
3. Run the test suite:

   ```bash
   dotnet test GenericSequenceGenerator.sln
   ```

4. Open a pull request describing the change and its verification.

## Commit guidelines

Use concise, imperative commit messages. Include tests when changing behavior, and avoid committing generated build artifacts.
